## 🚀 Featured Projects

### 🔧 [Fault Prediction on Live Manufacturing Data — Volkswagen](https://pmv4-analytics.streamlit.app)
End-to-end pipeline on real production sensor data: ingestion via API → cleaning & validation → ML defect detection → a self-service Streamlit dashboard with a RAG assistant, so non-technical factory staff can investigate results in plain language.
`Python` · `ML` · `ETL` · `Streamlit` · `RAG`

### 🛡️ [Agent Guardian — Runtime Governance for AI Agents](https://agent-guardian-orbit.lovable.app)
My M.Sc. thesis: a guardrail layer that validates autonomous AI-agent actions against policies **before** they execute. Policy-as-code, runtime monitoring & observability, deployed on Docker/Kubernetes, evaluated with statistical testing.
`Agentic AI` · `Policy-as-code` · `Kubernetes` · `Observability`

### 🌀 ArchesWeather — ML Typhoon Forecasting
Multi-day autoregressive time-series forecasting (7-day rollouts, six variables). Evaluated with RMSE & CRPS, and traced physically impossible outputs back to an upstream data-quality issue through root-cause analysis.
`Time-series` · `Forecasting` · `Data quality`

### 🕸️ TinyGraphLLM — Explainable & Debiased Graph Reasoning
Explainability + fairness framework on graph reasoning; reduced statistical parity gap from **0.62 → 0.34** while preserving performance.
`PyTorch Geometric` · `Explainability` · `Fairness`
